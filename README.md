# AWS Skill Builder – Hands-on Labs

This repository contains hands-on projects developed during multiple AWS Skill Builder courses, covering a wide range of AWS services, architectures, and workloads.

The purpose of this repository is to practically demonstrate and validate cloud knowledge acquired through AWS Skill Builder courses and certificates, by providing real, deployable examples using Infrastructure as Code (Terraform) and application-level implementations when applicable.

⸻

## 🎯 Goals of this repository
	• Provide practical evidence of AWS Skill Builder course completion
	• Serve as a technical portfolio of AWS hands-on projects
	• Act as a learning reference for AWS services and Terraform patterns
	• Support professional growth in cloud architecture and infrastructure engineering

⸻

Each folder in this repository represents a standalone project developed for a specific AWS Skill Builder course. Every project includes its own README.md with detailed explanations, architecture, and learnings.
